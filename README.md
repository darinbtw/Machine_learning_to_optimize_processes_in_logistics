# Использование машинного обучения для оптимизации логистических процессов

## Обзор Проекта

Этот проект представляет собой курсовую работу, посвященную исследованию и практическому применению методов машинного обучения (ML) для повышения эффективности логистических процессов. Основная цель — Исследование методов машинного обучения и тестирование моделей для оптимизации ключевых показателей, таких как время доставки.

### Ключевые Задачи

*   Проведение комплексного исследования методов ML в логистике.
*   Анализ существующих проблем логистики (задержки, риски, управление затратами).
*   Разработка и сравнение прогностических моделей для оценки времени доставки.
*   Демонстрация практических примеров применения ML для улучшения прозрачности и автоматизации логистической цепочки.

## Методология и Инструментарий

### Набор Данных

В качестве основы для исследования использовался реальный набор данных **Amazon Delivery**, содержащий более 43 000 записей о заказах.

### Инструменты и Библиотеки

Проект реализован на языке **Python** в среде **Jupyter Notebook**.

| Категория | Инструмент / Библиотека | Назначение |
| :--- | :--- | :--- |
| **Язык** | Python 3.12.6 | Основной язык программирования |
| **Среда** | Jupyter Notebook | Интерактивная среда для анализа данных |
| **Обработка данных** | `pandas`, `numpy` | Манипуляция и предобработка данных |
| **Визуализация** | `matplotlib`, `seaborn` | Создание графиков и визуализаций |
| **Машинное обучение** | `scikit-learn`, `XGBoost` | Разработка и тестирование моделей |

## Структура Репозитория

| Папка/Файл | Описание |
| :--- | :--- |
| `data_files/` | Исходные и обработанные наборы данных. |
| `exel_files/` | Дополнительные данные в формате Excel (например, данные о розничных запасах). |
| `images/` | Визуализации, графики и результаты анализа данных. |
| `amazon_delivery_analyz.ipynb` | Ноутбук с анализом данных и предварительной обработкой. |
| `amazon_delivery_ml.ipynb` | Основной ноутбук с реализацией и сравнением различных моделей машинного обучения. |
| `amazon_delivery_XGBOOST.ipynb` | Детальный анализ и настройка модели XGBoost. |
| `graphics.ipynb` | Ноутбук, посвященный созданию графиков и визуализаций для презентации. |

## Результаты

В ходе работы было установлено, что модели **Random Forest Regressor** и **XGBoost Regressor** показали наилучшие результаты в прогнозировании времени доставки, достигнув точности **R² около 79%**.

Это подтверждает эффективность применения продвинутых методов машинного обучения для:
*   Снижения операционных расходов.
*   Повышения точности прогнозов и планирования.
*   Улучшения качества обслуживания клиентов.
